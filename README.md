# Wizard Chess 3D

An atmospheric 3D Wizard Chess experience built with Three.js, React, and Vite. Features a Gothic cathedral sanctum, custom procedural stone & flame shaders, sculpted piece models, and stylized fracture & debris physics upon captures.

## Features

- **3D Living Chessboard:** Full 3D board set in an atmospheric Gothic cathedral with dynamic firelight and shadows.
- **Combat & Shatter Effects:** Captures trigger dramatic melee strikes and stone shatter physics.
- **Multiple Camera Modes:** Player Cam, Overhead, Side Profile, and Wide Cathedral views.
- **Tactical Opponent:** Single-player tactical AI with instant AI move options.
- **Responsive Controls:** Mouse orbit/pan/zoom and touch gestures for mobile.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Clone the repository:
   ```bash
   git clone https://github.com/jtggamer2295/wizard-chess-3d.git
   cd wizard-chess-3d
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Three.js** - 3D scene rendering, lighting, materials, and physics debris
- **React 19** - User interface & HUD
- **Vite** - Bundler and development server
- **TypeScript** - Type definitions
